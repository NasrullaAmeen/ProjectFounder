# Commands

User/agent-invokable command definitions that drive ProjectFounder workflows.

- [`new-project.md`](./new-project.md) — found a new project (capture + classify, Phase 0). Drives `workflows/new-project.md`.
- [`brainstorm.md`](./brainstorm.md) — run Discovery + Brainstorm against an already-classified project (Phase 1). Drives `workflows/brainstorm.md`.
- [`requirements.md`](./requirements.md) — run Gap Analysis + Feature Discovery + Requirements against a Discovery-lifecycle project (Phase 1). Drives `workflows/requirements.md`.

Status: Phase 0 and Phase 1 implemented (agent-executed, no code — see `docs/DECISIONS.md` D005). All other planned commands not yet added.
