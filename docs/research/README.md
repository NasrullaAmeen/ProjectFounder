# Research

ProjectFounder's own research folder.

Contains research reports about ProjectFounder itself (meta-research — evidence and synthesis that feed spec improvements), as opposed to the research artifacts ProjectFounder generates for downstream projects (those land in `output/<project>/RESEARCH.md`, see `output/README.md`).

## Reports

- `2026-09-08-projectfounder-deep-research.md` — Deep research on how to improve ProjectFounder (blogs, websites, GitHub, Hacker News, Reddit). Completed 2026-09-08.

## Conventions

All future research reports in this folder follow this naming convention:

```text
YYYY-MM-DD-<slug>.md
```

- `YYYY-MM-DD` — the date the research was completed.
- `<slug>` — short kebab-case name of the research topic.

New reports are added as sibling files here; this README is an index of all reports, so add a one-line entry to the Reports list when a new report lands.
