# Output

Generated project outputs land here, one directory per project (see ProjectFounder-idea.md, Section 122 — Project Output Structure):

```text
output/
└── <project>/
    ├── idea.md
    ├── README.md
    ├── PROJECT.yaml
    ├── SPEC.md
    └── ...
```

Contents of this directory (other than this README) are generated artifacts and are git-ignored — see `.gitignore`.
